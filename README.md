# Kwaliteitssysteem PVI Clinic B.V.

ISO 9001:2015 kwaliteitssysteem **én** operationele infrastructuur van de praktijk.

**Twee doelen:**
1. **Auditbaar** — de DEKRA ISO 9001-audit doorstaan. Zie [`00_AUDIT_2026_PLAN.md`](00_AUDIT_2026_PLAN.md).
2. **Werkend** — het systeem kent de terugkerende taken (voorraadcontroles, interne audits, directiebeoordeling, klachten, KPI's), draait ze en bewaakt of ze gebeuren — zodat de praktijk structureel beter loopt.

**Bron-van-waarheid:** markdown in deze repo. Word/PDF = export voor de auditor.
